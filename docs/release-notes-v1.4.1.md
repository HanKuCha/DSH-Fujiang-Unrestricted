# v1.4.1

修复 REA 6.9 工具定义引起的 WorkBuddy `11129 invalid_function_parameters`。账号池网关可能将该错误包装成 `503 no_healthy_account`。

REA 6.9 的部分字符串字段声明了 `^[^\uD800-\uDFFF]*$`。真实上游对照中，一个携带该声明的普通测试工具即可触发错误。相同的完整 311 个工具定义，在模型侧副本处理这 15 处声明后得到正常回复。

新增宿主 `schema-compat.mjs`，在工具说明组装阶段生成模型侧兼容副本，支持会话层的只读请求对象。工具名称、输入字段、必填项及其他校验声明保持原值，原始 Schema 和 REA 服务端继续执行 Unicode 校验。

验证覆盖原对象保持完整、其他约束、默认值与示例、幂等性，真实 DSH LLM 出口、两个提供商的模型回复，以及 REA 的合法路径与异常 Unicode 参数处理。

最终预设为 `.coop.12`。66 项安装检查、桌面和手机入口各 8 项原生回归、13 项通信回归通过。真实 Agent 携带完整 255 个 REA 工具完成回复，原始执行 Schema 校验保持完整。

桌面安装器与 DSHA 包共同包含兼容模块。安卓真机仍需对应设备验收。
