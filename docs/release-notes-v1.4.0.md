# v1.4.0

集成中文 fujiang-pojia 0.20.13 的功能与默认人格，并保留插话回应。

- 可编辑提示词、提示词卡片、实际生效预览和输入区开关。
- 九类内置知识、167 条记录，按需加载分类内容。
- 漏洞报告的持久化、状态管理与 Markdown 导出。
- 任务创建、会话绑定、阶段进度、完成标记与自动续跑。
- REA、AboutSecurity 按需安装与启停目录。
- 原生的 kb_match、campaign_upsert、finding_upsert、skill_search、skill_read 和 pipeline_next 工具。

真人插话后若模型直接调用工具，会先补充可见回应再继续原任务。任务面板与自动续跑使用独立的消息来源。绑定任务后启用流程规则，忙碌会话等待调度。

默认人格去掉“爸爸”称呼和 TG 频道前缀，保留用户选择的原版情色语气。已有 prompt-custom.json 配置优先生效。

安装器沿用本地维护链接、备份旧文件、拒绝降级并逐文件核对实际链接，补齐深层知识库路径所需的长路径支持。旧 240＋3 技能挂载由上游分类知识与按需库接替。

保留 DSH 标准本地技能发现，验证既有用户技能与上游分类一同进入模型请求。现有 REA MCP 与独立安装的 ARTEX 可继续使用，技能面板只管理自己安装的副本。

桌面 EXE、桌面 ZIP 和 DSHA ZIP 在同一 Release 提供。DSHA 包共用功能源码和客户端，Android 真机仍需设备验证。

原生验收使用 Windows 和 DSH 0.2.2-rc.1，涵盖配置编辑、开关、知识目录、报告、任务、六个工具的真实分发和插话回应。模型行为回归使用夹具，其他电脑和外部引擎依赖需要结合实际环境验收。

66 项安装回归、桌面与手机入口各 8 项原生检查、13 项通信回归通过。本机安装后的 192 个发布文件完成哈希核对，实际 Desktop 中已确认输入区开关及五个功能标签。

Windows 面板实际完成 REA 6.9.0 与 AboutSecurity 249 个技能的下载安装。REA 通过 255 个 MCP 工具的发现与只读调用验证，并支持从独立配置文件迁移既有引擎环境变量。

已有有效本地链接、且本插件没有 NPM 运行依赖时，升级通过目录共享校验复用链接，减少重复解析整个 profile 的依赖。首次安装仍通过官方 CLI 注册。

详细来源与衔接改动见 [上游同步记录](https://github.com/HanKuCha/DSH-Fujiang-Unrestricted/blob/main/docs/upstream-sync.md)。
