桌面和 DSHA 共用一份工作助手核心源码，同一个 Release 提供两类安装包。

## 选对安装包

- **Windows Desktop**：下载 `DSH-Fujiang-Installer.exe`，退出 DSH（含托盘），运行 EXE 并点击安装。EXE 已内嵌预设及 240 + 3 个技能，可单独运行；完整桌面 ZIP 另附。
- **DSHA 安卓版**：下载 `DSH-Fujiang-DSHA-v1.2.0.zip`，在 DSHA → 插件导入，或粘贴这个具体附件的下载链接，安装启用后按 App 提示重启 Web，在新会话选择「工作助手」。手机包不含 EXE/CMD，不增加原生二进制依赖。

两端保留同一份内容回应规则与协作改进：主动澄清、阶段汇报、最新目标合并、DSH 工具/技能和子代理指引。默认称呼已改成自然称呼，不再要求称用户为“爸爸”。

DSHA 适配增加可迁移的技能路径、Ubuntu/Android 环境说明与运行时上下文，使用现有模型、密钥、推理等级及设备授权。根 `package.json` 提供 DSHA 可识别的 bundle 声明；手机适配层由共享预设生成，避免两套提示词各自维护。

## 验证范围

- Windows：19 项隔离安装检查及真实 DSH 随附 CLI 检查通过，含单 EXE、自定义/特殊字符路径、重复升级和保留自建技能。
- 手机包：DSHA 原始 ZIP 解包、插件根发现及包校验函数通过；非法版本和缺失补丁的负控均被拒绝；源码/打包检查通过。
- 手机适配引用的 28 项官方模块名称均可在 DSHA 锁定依赖中找到；当前 Desktop `0.2.1-rc.5` 的组合、工具注册和技能发现通过。
- 尚未做安卓真机安装、DSHA `0.2.1-rc.2` 中的实际工具执行或旧版本设备矩阵验证。这些电脑检查不等同于手机实测。

本包不捆绑第三方回退、编辑或即时插话插件；这些消息交互功能与本预设分开安装和验证。不承诺改变模型自身能力或测得拒答率提升。

## 源码与校验

`mobile-dsha` 保留手机版适配的验证分支，功能合入 `main` 后统一维护。桌面源码在 `src/`，手机适配与测试在 `mobile/`，共同预设与技能在 `payload/`。附件 `SHA256SUMS.txt` 可核对三个安装包。
