# fujiang-pojia 上游同步

核对日期为 2026-11-16，集成版本为 1.4.0。

## 基线

本次功能和人格采用中文 0.20.13，提交为 `338b598386aed60d4e7bdbf60ebb526af0b47697`。源码保存在 [upstream-0.20.13 标签](https://github.com/HanKuCha/fujiang-pojia/tree/upstream-0.20.13)。最新活跃衍生版 0.21.0 和后续提交保存在同一 fork 的主分支。

完整插件位于 `payload/dsh-ws-helper-preset/upstream`。保留上游的编辑面板、输入区开关、知识库、报告、任务管理、按需下载库与相关模块，统一由本项目的安装包注册。

## 默认人格

默认文案来自上游 `prompt-custom.json`。按用户要求去掉“爸爸”称呼和 TG 频道标记，激活词“富江”的回复调整为“富江在线，开始任务”。保留原版情色语气，其余人格正文沿用上游。

人格由上游的动态 section 注入管理，工作助手预设提供通用工具组合。编辑、卡片切换、启停和追加/替换模式由原版面板处理。已有 `$DSH_HOME/prompt-custom.json` 配置优先生效。

## 协作衔接

- `communication.mjs` 负责真人插话的可见回应。模型直接调用工具时，通过同款模型的独立文本请求补回应，再放行原工具流。
- 回应模块作用于工作助手根会话，以及富江人格已开启的其他根会话。子代理执行结果由主代理汇报。
- 自动续跑与面板启动使用 `fujiang-campaign` 来源，真人输入继续使用 `user` 来源。
- 流程规则在会话绑定任务时生效。自动续跑等待忙碌会话，按实际调度增加轮次，卸载时清理计时器。

## 兼容与安装

- Host SDK 按所选 DSH 的 `profileContext.installAnchor` 解析，兼容 Desktop ASAR 中的模块位置。
- 修正上游 Host 仍显示 0.20.12 的常量，当前上游版本显示为 0.20.13。
- 客户端模块 id 对齐桌面与手机各自的插件包名。
- 原 240＋3 技能挂载由上游的九类知识与按需库接替。升级会备份旧目录，用户添加的本地文件可保留取回。
- 标准本地技能发现覆盖用户与 profile 目录，已有 ARTEX 等技能仍可在模型请求目录中出现。
- REA 可从 `fujiang-skills/rea-env.json` 读取原 MCP 的引擎环境配置，支持迁移既有 Ghidra、Java 与 IDA 路径。
- 安装器保留维护链接、拒绝降级、备份 profile，并逐文件校验实际链接内容。重复的旧入口通过 overlay 禁用。
- 完整文件校验覆盖更深的知识库路径，EXE 启用 .NET Framework 与 Windows 长路径支持。

## 验收

原生运行时验证覆盖默认文案、卡片编辑、即时开关、九类知识目录、按需技能目录、报告持久化与导出、任务绑定与进度、六个原生工具的真实分发，以及先回应后执行的工具顺序。

通信回归覆盖已有正文、无正文、连续工具调用、并行调用、辅助请求失败、用户停止、子代理与目标纠正。安装回归覆盖中文和特殊字符目录、独立 EXE、目录/EXE/CLI 输入、旧 YAML、已有维护链接、拒绝降级、旧插件配置与卸载。

本机宿主为 Windows 和 DSH 0.2.2-rc.1，模型行为回归使用夹具。外部技能的下载、引擎依赖、其他电脑及 Android 真机应结合实际环境继续验收。

## 1.4.3 后续调整

功能框架继续基于 0.20.13，默认人格改用本项目 v1.3.1 的文字，并加入简短回复与 REA 参数指引。补回应继承主助手当次已装配的系统提示词，任务清单恢复按证据逐阶段核对。升级对已知旧默认文字按 SHA-256 精确匹配，备份配置后更新正文，自定义正文与提示词卡保留。
