# DSHA 安装包

当前版本为 1.4.4，使用中文 fujiang-pojia 0.20.13 功能框架和直接专业的默认提示词，集成插话回应、压缩后目标核对、按需工具发现及任务清单核对。

## 安装

从同一 Release 下载 `DSH-Fujiang-DSHA-v1.4.4.zip`，在 DSHA 的插件管理中导入本地包，或填写该具体附件的下载链接。完成导入后重新启动 DSHA 内的 DSH 服务。

根 `package.json` 声明插件、客户端面板和模块导出，包内包含共享的上游代码、知识库、默认人格与回应模块。手机包使用 DSHA 的插件导入入口。

## 功能

提示词编辑、输入区开关、知识库、报告、任务面板和按需技能目录与桌面共用源码。默认人格采用本项目 v1.3.1 的文字，加入简短回复和 REA 工具参数说明。

进入会话后可通过输入区的“富江破甲”入口打开设置。“工作助手”作为兼容预设保留，其他原生模式在富江开启时也会获得插话回应。

DSHA 中 DSH 的数据位于其 Ubuntu 环境内，配置文件由该环境的 DSH_HOME 决定。按需安装 REA 时，需要满足相应 Node.js、npm 与引擎要求。外部技能的安装状态和失败原因在面板显示。

## 验证范围

包结构、模块名称、客户端声明和与桌面共用的原生运行时行为已进行隔离检查。验收宿主为 DSH 0.2.2-rc.3，Android 真机仍需设备验证。手机中的 WebView、文件访问和外部引擎行为以实际设备为准。
